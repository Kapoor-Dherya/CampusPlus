# CampusPlus 🎓

A campus event discovery platform built with React.

### Features
- Search and filter events
- Save favorite events
- View event details
- Register for events
- Dark/Light mode
- Responsive design

### Tech Stack
- React
- Vite
- JavaScript
- CSS
